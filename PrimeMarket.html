PrimeMarket

3-member Agile team

A multi-vendor ecommerce platform where independent sellers run their own storefronts within a shared marketplace, with real-time updates and hosted media for product listings.

situation

In a shared marketplace, if vendor inventories and orders aren't kept isolated, one seller's stock change can leak into another's view — and if order status doesn't update live, a buyer has to keep refreshing to see if anything moved.

task

As part of a three-member Agile team, deliver the customer-facing side — browsing, cart, wishlist, checkout, order management — so each vendor's storefront stays isolated and status updates reach the customer immediately.

action

To get status changes to the customer without a refresh or polling loop, I built the frontend in Angular 21 using Signals for local UI state and RxJS to consume a SignalR event stream pushed straight from the backend when an order updates. Checkout calls a JWT-authenticated ASP.NET Core (.NET 10) API following Clean Architecture, and product images are served through Cloudinary rather than the app server, so image requests don't compete with API traffic under load.

result

Buyers see order-status changes appear live during checkout, sellers manage listings independently within the same platform, and payments run through Stripe end to end.

Architecture notes

  • Background job processing via Hangfire for scheduled or deferred marketplace tasks.
  • Payments integrated through Stripe's API rather than a custom-built processor.
  • Media offloaded to Cloudinary instead of local or database storage, keeping the app server stateless for images.
