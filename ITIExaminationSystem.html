ITI Examination System

solo project

An ASP.NET Core MVC platform for running ITI courses and online exams — covering course enrollment, exam authoring, randomized assignment, timed attempts, and automatic grading across three distinct roles.

situation

An exam published with too few questions, or a multiple-choice question with two answers marked correct by mistake, gives students an unfair or broken test — and that's exactly the kind of bug that slips through when validation isn't enforced before publishing.

task

Build an exam authoring flow where an instructor physically cannot publish a broken exam.

action

Rather than trusting instructors to follow the rules manually, I put the validation in the publish step itself: an exam needs at least seven MCQ and three true/false questions, every MCQ must have exactly four choices with exactly one marked correct, and every true/false question needs a defined answer — publish is blocked outright if any of that fails. Because grading a full submission needed to happen as one atomic operation rather than row-by-row EF Core calls, I ran delivery and grading through SQL Server stored procedures and table-valued parameters instead.

result

An instructor can't accidentally publish an invalid exam, and every submission gets graded automatically the moment it's submitted, with results visible to the student immediately.

Architecture notes

  • Exam delivery and submission run through SQL Server stored procedures and table-valued parameters rather than plain EF Core queries, for the heavier grading logic.
  • Domain model separates academic structure (branch, track, course) from exam authoring (exam, question, choice) and from attempts and grading (submission, student answer).
  • ASP.NET Core Identity drives role-specific sign-in redirects — admin, instructor, and student each land on their own dashboard.
  • EF Core migrations apply automatically on startup.
